Before you start

  • Read-only access: This tool only asks for permission to read your tasks. It never creates, edits, or deletes anything.
  • Private by design: Everything runs locally in your browser—your lists and tasks are never sent to or stored on a server.
  • List groups are ignored: All lists are exported individually as a flat collection, regardless of how they are grouped in Microsoft To Do.
  • File attachments: Attachment details (file name, type, and size) are included in the JSON, but raw file contents are not downloaded.
